# ウィンドウ操作（Ctrl+w 系）

1 つの画面を分割し、片方のファイルを見ながらもう片方を編集する。

## 分割する

| キー | 動作 | この設定での別のキー / コマンド |
|---|---|---|
| `Ctrl+w s` | 上下に分割する | `<leader>s`、`:split`（`:sp`） |
| `Ctrl+w v` | 左右に分割する | `<leader>v`、`:vsplit`（`:vs`） |

## 移動する

| キー | 動作 |
|---|---|
| `Ctrl+w h` / `j` / `k` / `l` | 左 / 下 / 上 / 右のウィンドウへ移動する |
| `Ctrl+w w` | 次のウィンドウへ順に移動する |

## 閉じる

| キー | 動作 |
|---|---|
| `Ctrl+w c` | 今のウィンドウを閉じる（close） |
| `Ctrl+w o` | 今のウィンドウ以外をすべて閉じる（only） |

## 大きさを変える

| キー | 動作 |
|---|---|
| `Ctrl+w +` / `Ctrl+w -` | 高さを 1 行増やす / 減らす。`10 Ctrl+w +` のように回数を付けられる |
| `Ctrl+w >` / `Ctrl+w <` | 幅を 1 桁増やす / 減らす |
| `Ctrl+w =` | すべてのウィンドウを同じ大きさにそろえる |
