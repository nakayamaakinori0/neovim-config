# 挿入モードのキー

挿入モードのまま、ホームポジションから手を離さずに使えるキー。

## 編集

| キー | 動作 |
|---|---|
| `Ctrl+h` | カーソルの前の 1 文字を削除する（Backspace と同じ） |
| `Ctrl+w` | カーソルの前の 1 単語を削除する |
| `Ctrl+u` | 行頭までを削除する |
| `Ctrl+[` | 挿入モードを抜ける（Esc と同じ。この設定では `jj` も使える） |

## 補完

この設定では LSP の補完が入力中に自動で出る（`vim.lsp.completion`）。

| キー | 動作 |
|---|---|
| `Ctrl+n` / `Ctrl+p` | 次 / 前の候補を選ぶ。補完が出ていなければ、バッファ内の単語で補完を始める |
| `Ctrl+y` | 選んだ候補で確定する |
| `Ctrl+e` | 補完ウィンドウを閉じる（入力は確定前に戻る） |

## 矩形挿入

複数行の同じ位置に、まとめて文字を入れる。

1. 普通のモードで `Ctrl+v` を押し、矩形選択を始める
2. `j` / `k` で行を選ぶ
3. `I` を押し、入れたい文字を打つ（行末に足すなら `$` で選んでから `A`）
4. `Esc` で、選んだすべての行に反映される
