# usage

Neovim の使い方メモ。この設定で実際に使う操作を、話題ごとに書く。

## 命名規則

`<kebab-case-topic>.md`（例: `search-and-replace.md`）。番号は付けない。

## 一覧

| メモ | 内容 |
|---|---|
| [search-and-replace.md](search-and-replace.md) | 全文検索から置換する（quickfix） |
| [netrw.md](netrw.md) | ファイルツリー（netrw）の操作 |
| [insert-mode.md](insert-mode.md) | 挿入モードでの削除・補完・矩形挿入 |
| [window.md](window.md) | ウィンドウの分割・移動・閉じる・大きさ（Ctrl+w 系） |
