# ファイルツリー（netrw）

nvim-tree の代わりに本体の netrw を使う。ツリー表示（`netrw_liststyle = 3`）で、左に幅 30 で開く。

## 開く・閉じる

| キー / コマンド | 動作 |
|---|---|
| `<leader>e` | 左にツリーを開く。もう一度押すと閉じる（`:Lexplore`） |
| `:Explore` | 今のウィンドウで、今のファイルのディレクトリを開く |

## ツリーの中の操作

| キー | 動作 |
|---|---|
| `<CR>` | ファイルを開く / ディレクトリを展開・折りたたむ |
| `-` | 親ディレクトリへ |
| `%` | ファイルを作る |
| `d` | ディレクトリを作る |
| `R` | 名前を変更する |
| `D` | 削除する |
| `i` | 表示形式を切り替える（一覧 / 詳細 / 横並び / ツリー） |
| `gh` | 隠しファイルの表示を切り替える |
