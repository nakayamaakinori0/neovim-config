# バッファとジャンプ

## バッファを切り替える

| キー / コマンド | 動作 |
|---|---|
| `]b` / `[b` | 次 / 前のバッファへ（標準） |
| `]B` / `[B` | 最後 / 最初のバッファへ（標準） |
| `,bt` | バッファ一覧を telescope で絞り込んで開く |
| `:ls` | バッファ一覧を表示する |
| `:b {名前の一部}` | 名前で開く。`Tab` で補完できる |
| `Ctrl+^` | 直前のバッファと行き来する |
| `,bx` | 今のバッファを閉じる（`:bdelete`） |

## ジャンプリスト

定義ジャンプ（`gd`）や検索で飛んだ場所の履歴をたどる。

| キー | 動作 |
|---|---|
| `Ctrl+o` | 前の場所へ戻る |
| `Ctrl+i` | 次の場所へ進む（ターミナルでは `Tab` と同じキー） |
| `:jumps` | 履歴を表示する |
