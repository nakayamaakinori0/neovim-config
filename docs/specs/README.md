# specs

この Neovim 設定の開発計画・仕様を置く場所。

## 命名規則

`NNNN-<kebab-case-title>.md`

- `NNNN`: 4 桁の連番（`0001` から）。既存の最大番号 + 1 を使う
- 番号は再利用しない。廃止した spec も削除せず、ステータスを `廃止` にして残す

## ステータス

各 spec の先頭に書く。

| ステータス | 意味 |
|---|---|
| 草案 | 検討中 |
| 進行中 | 作業中 |
| 完了 | 実施済み |
| 廃止 | やめた（理由を本文に残す） |
