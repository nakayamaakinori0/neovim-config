# 0005 fugitive をやめ、差分は本体の difftool で読む

- ステータス: 完了
- 作成日: 2026-11-26
- 完了日: 2026-11-26

## 1. 背景

コードはほとんど AI に書かせるので、Neovim でやることは差分を読むことが中心になった。読みたいのは、手元とリモート、コミット 1 つ、ブランチ間の差分。

fugitive で読もうとしたが、使いにくかった。

| 困ったこと | 中身 |
|---|---|
| 押す行で動きが変わる | コミット画面の `Enter` は、`diff --git` の行なら左右の diff、`+++` の行ならファイル 1 つ、`parent` の行なら親のコミットを開く |
| 戻り方が決まらない | 同じタブで開くと、`Ctrl+o` を何回押せば戻るかがジャンプの履歴で変わる（2 回のときも 3 回のときもあった） |
| 画面でキーが違う | `:Git` の一覧では `dv`、コミット画面では `Enter` か `O` で左右の diff を開く |

## 2. 方針

fugitive を外す。差分は Neovim 0.12 に入っている `nvim.difftool` を `git difftool -d` から開いて読む。範囲は git の書き方でそのまま渡せるので、手元・リモート・コミット・ブランチのどれも同じ操作（`]q` でファイル、`]c` で変更）で読める。

`diffopt` に `linematch:60` と `inline:char` を足し、左右の diff で行の中の変わった文字だけを光らせる。

ステージ・コミット・rebase はターミナルで git コマンドを打つ。開いているファイルの中の変更は gitsigns で見る。

| 案 | 採らなかった理由 |
|---|---|
| fugitive を続ける（コミット画面を畳み、`O` で新しいタブに開く） | 動くようにはできたが、押す行や画面ごとに覚えることが多い |
| diffview.nvim を入れる | 操作体系が独自で使いにくかった |
| lazygit.nvim を入れる | 差分を読むだけなら本体で足りる |
| delta を git の pager にする | 読めるが、ファイルの一覧から選んで移れない |
| `:GDiff` などを自作する | 本体の difftool で足りる。自作で保守するものを増やしたくない |

`linematch` を入れると、3 方向の diff の `d2o` / `d3o` で衝突の印（`=======` など）が残る。衝突は印を手で直すことにして、普段の読みやすさを優先した。
