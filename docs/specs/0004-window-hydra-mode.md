# 0004 ウィンドウ操作を続けて押せるモードを足す

- ステータス: 完了
- 作成日: 2026-11-04
- 完了日: 2026-11-04

## 1. 背景

ウィンドウのリサイズは標準の `Ctrl+w >` などで行うが、`Ctrl+w` が効くのは直後の 1 キーだけなので、少しずつ広げるたびに `Ctrl+w` を押し直す必要があり使いにくい。

`nvim --clean` で確かめた標準の動き:

| 押したキー | 結果 |
|---|---|
| `Ctrl+w` `>` `>` `>` | 幅は 1 桁しか変わらない。残りの `>` はインデントの操作になる |
| `Ctrl+w` を押しっぱなし | `Ctrl+w Ctrl+w`（次のウィンドウへ移動）が繰り返される |

## 2. 方針

自作のプラグインは作らず、入っている which-key の Hydra モード（`require("which-key").show({ keys = "<c-w>", loop = true })`）を使う。`Esc` を押すまで `Ctrl+w` が効き続けるので、`>` や `+` を続けて押せる（押しっぱなしのリピートも効く）。

| 案 | 採らなかった理由 |
|---|---|
| 自作する | which-key で足りる。自作で保守するものを増やしたくない |
| 標準のまま（`10 Ctrl+w >`、マウス） | 回数を先に決める必要があり、見ながら合わせにくい |
